# Code of conduct

Short, and specific to this repository. It is deliberately not the Contributor
Covenant: that document is longer than this project's contributor base, and
adopting one you will not apply is worse than writing a short one you will.

## What is expected

**Be exact, and say when you are not.** This repository is built on that. The
README's numbers are measured rather than estimated; the source adapters record
whether they were verified against live data or only fixtures; the tests are
named as statements about the failure they prevent. "I tried it, here is the
output" is worth more here than "this is broken".

**Being wrong is fine. Being sure and wrong is not.** A confident wrong
conclusion costs more than three honest probes, so a correction is not a defeat.
If someone shows you evidence against what you said, that is the system working.

**Not welcome:** harassment, personal attacks, and the dismissive review comment
that teaches nothing. Disagreeing with the code, the design or the README is none
of those, and is welcome.

## Scope

Issues, pull requests, discussions and commit messages on this repository.

## Reporting and enforcement

Raise it in the thread if it can be raised there. If it cannot, open an issue
saying only that you have something to report, and a private channel will be
arranged — the same route `SECURITY.md` uses for vulnerabilities.

One person reads it and decides what happens, in the open where that is possible.
What you can expect is attention and a decision, not a process and not a
schedule — this is one person's project, not a funded program.
