# Last Session — восстановление контекста

Собрать, чем занимались и на чём остановились. **Источник истины — сырой транскрипт**, а не память и не кэш. Всё, что можно, запускать параллельно.

## Шаг 1: Найти предыдущую сессию

Транскрипты живут в `~/.claude/projects/<project-slug>/*.jsonl`.

```bash
ls -t ~/.claude/projects/*/*.jsonl | head -5
```

- Самый свежий файл — **текущая** сессия (пишется прямо сейчас). Пропустить его.
- Следующий — **предыдущая**. Если каталогов несколько, выбрать тот, чей slug соответствует текущему `cwd`.
- Если аргумент задан — искать сессию по теме, а не просто последнюю.

## Шаг 2: Прочитать хвост (главное — «на чём остановились»)

Последние обмены важнее всех остальных. Из хвоста транскрипта извлечь:
- последний запрос пользователя и что на него ответили;
- незавершённое действие (запущенный процесс, открытый вопрос, обещанный следующий шаг);
- явные «стоп-сигналы»: вопрос без ответа, ошибка, ожидание решения.

Формат JSONL: `{ type, message: { role, content } }` — **разворачивать через `.message`**, верхнеуровневых `role`/`content` нет.

## Шаг 3: Параллельно — фактические следы работы

Запустить одновременно:

- `git log --oneline -15 --format='%h %cd %s' --date=format:'%m-%d %H:%M'` — что реально закоммичено
- `git status --short` — **незакоммиченное = незавершённое**, самый честный признак «где бросили»
- `git stash list` — отложенное
- arca `thread_detail` / `thread_list` — сквозной сюжет, если тема тянется через сессии
- arca `observation_search` — типизированные уроки по теме

Если сессия длинная — не читать целиком: взять начало (что затевали), середину по ключевым переходам, хвост (где встали).

## Шаг 4: Отчёт

Выдать **компактно**, без пересказа диалога:

```
## Прошлая сессия — <дата, длительность>

**Занимались:** 2-4 пункта, главное первым

**Сделано:** коммиты/файлы/факты — со ссылками `file:line` и хэшами

**Остановились на:** одна конкретная точка — что именно осталось незакрытым

**Открытые хвосты:**
- незакоммиченное: <файлы>
- незавершённое: <процесс/вопрос/решение>

**Следующий шаг:** одно предложение — что логично сделать первым
```

## Правила

- **Не выдумывать.** Не нашёл — скажи «не нашёл», а не «вероятно, мы...».
- Различать **сделанное** (есть коммит/файл) и **обсуждавшееся** (только разговор).
- Хвост важнее объёма: лучше точная точка остановки, чем полный конспект.
- Если предыдущая сессия — это та же тема, что и текущая после `/compact`, сказать об этом прямо.
- Не начинать работу — только восстановить контекст и дождаться команды.
